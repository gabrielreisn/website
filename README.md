## Digital Garden

Source for [gabrielreis.dev](https://gabrielreis.dev). Originally an adaptation of [Eleventy duo](https://github.com/yinkakun/eleventy-duo), now built on:

| Layer   | Tech                                                                                                 |
| ------- | ---------------------------------------------------------------------------------------------------- |
| Site    | [Astro](https://astro.build) (server output) with [React](https://react.dev) components              |
| CMS     | [EmDash](https://emdashcms.com) — admin at `/_emdash/admin`                                          |
| Styling | [Tailwind CSS v4](https://tailwindcss.com) — theme tokens in [`src/styles/global.css`](src/styles/global.css) |
| Runtime | Cloudflare Workers + D1 (content) + R2 (media) + KV (sessions)                                       |
| Infra   | [Pulumi](https://www.pulumi.com) in [`infra/`](infra/)                                              |

## Project layout

```
astro.config.mjs        Astro + EmDash + Tailwind + Cloudflare adapter
wrangler.jsonc          Local dev Worker config (no resource IDs)
seed/seed.json          EmDash content model: `posts` collection + `tag` taxonomy
emdash-env.d.ts         Generated collection types (regenerated by `pnpm dev`)
src/
  worker.ts             Worker entry (EmDash handler + cron for scheduled publishing)
  live.config.ts        EmDash live content collection
  layouts/Base.astro    HTML shell, SEO via <EmDashHead>
  components/*.tsx      React UI (Header, Footer, PostList, TagList, …)
  pages/                /, /blog, /about, /posts/[slug], /tags/[tag], /portfolio, rss, sitemap, robots
  lib/                  site config, post helpers, JSON-LD builders (structured-data.ts)
  plugins/              Local EmDash plugin that swaps EmDash's default JSON-LD for ours
  styles/global.css     Tailwind entry, design tokens, rich-text styles
infra/                  Pulumi program (D1, R2, KV, Worker deploy, custom domains)
scripts/                EmDash maintenance: schema sync
```

## Local development

```bash
pnpm install
pnpm exec emdash secrets generate --write .env   # once: creates EMDASH_ENCRYPTION_KEY
pnpm dev
```

- Site: http://localhost:4321
- Admin: http://localhost:4321/_emdash/admin — the setup wizard applies `seed/seed.json` and registers your passkey.

D1, R2 and KV are simulated locally by Wrangler (state lives in `.wrangler/state`).

## Content model

`posts` mirrors the old Notion database:

| Old Notion field | EmDash                                           |
| ------------ | ------------------------------------------------ |
| Title        | `title` (string)                                 |
| Slug         | built-in entry slug → `/posts/{slug}`            |
| Date         | built-in publish date (`publishedAt`)            |
| Published    | built-in draft / published / scheduled status   |
| Description  | `description` (text) — falls back to an excerpt |
| Tags         | `tag` taxonomy → `/tags/{slug}`                  |
| Page body    | `content` (Portable Text)                        |

`projects` (portfolio, `/portfolio/{slug}`): `title`, `summary`, `role`, `period`, `url`, `repository`, `cover`, `featured`, `content` (case study), plus a `stack` taxonomy.

The seed only runs when a database is first set up. After changing `seed/seed.json`, add the missing collections/fields/taxonomies to a live site with:

```bash
EMDASH_URL=https://gabrielreis.dev EMDASH_TOKEN=<token> pnpm emdash:sync-schema --dry-run   # then without --dry-run
```

It's additive only (never renames or deletes). Create the token in the admin under **Settings → API Tokens**.

## Deploying (Pulumi → Cloudflare)

Pulumi owns the stateful resources and domains, and passes their IDs into `astro build` + `wrangler deploy`:

```
pulumi up
  ├─ cloudflare.D1Database      <worker>-db         (protected)
  ├─ cloudflare.R2Bucket        <worker>-media      (protected)
  ├─ cloudflare.WorkersKvNamespace <worker>-sessions
  ├─ command.local.Command      writes wrangler.production.jsonc → pnpm build → wrangler deploy
  └─ cloudflare.WorkersCustomDomain  (one per hostname)
```

The deploy step re-runs whenever anything under `src/`, `public/`, `seed/` or the build config changes.

### Requirements

- [Pulumi CLI](https://www.pulumi.com/docs/install/) (`brew install pulumi`)
- A Cloudflare API token with **Workers Scripts: Edit**, **D1: Edit**, **Workers R2 Storage: Edit**, **Workers KV Storage: Edit**, and on the zone **Workers Routes: Edit** + **DNS: Edit**
- Works on the **Workers Free plan** (bundle is ~19 MiB uncompressed; the limit is 64 MiB on both plans). The Free plan's real constraint is **10 ms CPU per request** — watch for Error 1102 in `wrangler tail` after deploying.
- The domain's zone on Cloudflare, with no conflicting DNS records for the hostnames (e.g. old Vercel `A`/`CNAME` records).

### First deploy

```bash
cd infra
pulumi stack init production
pulumi config set accountId <cloudflare-account-id>
pulumi config set zoneId <zone-id-of-gabrielreis.dev>
pulumi config set --path 'domains[0]' gabrielreis.dev
pulumi config set --secret emdashEncryptionKey "$(cd .. && pnpm exec emdash secrets generate 2>/dev/null)"
export CLOUDFLARE_API_TOKEN=<token>      # or: pulumi config set --secret cloudflare:apiToken <token>
pulumi up
```

Back up `emdashEncryptionKey` — it encrypts secrets stored in D1.

> **Finish setup right away.** On an empty database the first visitor to `/_emdash/admin` becomes the admin. Open the `adminUrl` stack output immediately after the first deploy, or put `/_emdash/*` behind [Cloudflare Access](https://docs.emdashcms.com/guides/authentication/).

`pulumi destroy` deliberately leaves the Worker in place (no delete hook, so a resource replacement can never take the site down) — remove it with `pnpm exec wrangler delete` if you really mean to.

Optional config: `workerName` (default `gabrielreis-dev`), `d1LocationHint` (default `enam`), `protectData` (default `true`; protects D1/R2 from `pulumi destroy`).

### Subsequent deploys

```bash
pnpm infra:up      # = pulumi up in ./infra
```
